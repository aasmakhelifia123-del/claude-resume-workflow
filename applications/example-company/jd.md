# Senior Full-Stack Engineer — Example Corp

> This is a fictional job description showing the layout. Your own
> applications get one folder each under `applications/`, each with a
> `jd.md`, `resume.md`, and optionally a `cover-letter.md`.

Example Corp is a 60-person SaaS building project management software for
design teams. We're hiring a Senior Full-Stack Engineer to own a meaningful
slice of the product end-to-end.

## What you'll do

- Ship features end-to-end across React/TypeScript on the frontend and
  Node.js on the backend.
- Own the data model and API surface for one of our core product areas.
- Partner with design and product on scoping, prototyping, and shipping
  in tight iteration cycles.
- Improve the developer experience — tests, tooling, CI, the things that
  compound for the rest of the team.

## What we're looking for

- 5+ years shipping production web applications.
- Strong React and TypeScript; comfort with at least one server-side
  language (Node, Python, Go).
- Track record of owning features end-to-end, including data model and
  API design.
- Bias toward shipping, with the judgment to know when to slow down.

## Comp

$120k–$150k base, equity, remote-friendly (US time zones).
